# Live named properties on element.dataset

The HTML dataset getter previously returned a fresh Proxy with a getter and setter on an empty object. Reading a present attribute by name worked in some cases while checking membership returned false and iteration returned no names. A script using `'notRenderedWidth' in image.dataset` therefore ignored an authored `data-not-rendered-width="10"`. The pinned WPT for image dimensions uses this check for hidden images, and its 2x variants use enumeration to adjust their natural-dimension expectations.

The element now keeps one DOMStringMap object. Lean reads the DOM's live attribute list and performs the HTML ASCII dash and case conversions. The JavaScript binding exposes the resulting own properties, descriptors, enumeration, prototype lookup, updates and deletions. An attribute with an empty value remains present. The DOMStringMap prototype also remains visible when an element has no attribute for the requested property. The shared HTML/SVG/MathML dataset getter uses the same binding.

Chrome read 10×10 from a hidden missing image with authored dimensions and 0×0 from its natural size getters. Detaching the same element preserved 10×10. Membership, enumeration, cloning, empty attributes and removal reflected the authored data in Chrome. Lean 4.33.1 compiled the new StringMap module and its backing-attribute theorem. A local source-extracted Node replay of the eight pinned dataset test scripts changed from 48/74 to 74/74. It used a simulated attribute host. All 87 distinct answers that host returned for the revised binding were independently checked against the compiled Lean implementation. Full native results are pending.
