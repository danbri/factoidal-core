## Theorems (`XPath4/SerializeTheorems.lean`)

Proved, no `sorry`; `#print axioms` gives `propext`, `Classical.choice`,
`Quot.sound` only:

* `escTextChar_eq_xml`: the XML output method escapes a text character as
  `XML.escapeText` (the serializer of `L4Factoidal.XML`) does, for a character
  that needs no character reference, with no character map, no
  normalization, encoding UTF-8.
* `jsonEscChar_canonical_eq_json`: the canonical JSON form (RFC 8785) escapes
  every character of U+0020 or above as `JSON.escapeChar` does.
* `jsonEscChar_eq_json`: the default JSON form, with `escape-solidus` false,
  no character map and UTF-8, escapes every character of U+0020 or above and
  outside U+007F..U+009F as `JSON.escapeChar` does.

Tested (`#guard`): the canonical escape of the 32 C0 controls is
`JSON.escapeChar`; Unicode normalization on the examples of UAX #15; BLAKE3 on
six inputs against the reference implementation.

Open: the round trip `parse-xml(serialize($d))` = `$d`, and the preorder of
`Doc.ofNodes`: https://github.com/danbri/factoidal/issues/1143.

## Not implemented

progress on another branch), `fn:parse-html` and `fn:html-doc`, UCA
collations (`fn:collation`, `collation-key`), the options of
`fn:deep-equal`, the `byte-order-mark` parameter, the JSON `record` rule
(an empty record field is written as `null`), `FULLY-NORMALIZED`. Each is
a failing qt4tests case today; tracking:
https://github.com/danbri/factoidal/issues/1101.
