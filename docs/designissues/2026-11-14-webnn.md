# WebNN graph validation and CPU execution (2026-11-14)

The WebNN implementation lives in `formal/lean4/L4Factoidal/WebNN/`. `Shape` supplies
broadcasting and flat/multi-index conversion; `Tensor` supplies data types and byte
encoding; `Infer` checks operands and infers output descriptors; `Move` implements data
movement; `Compute` supplies CPU kernels; `Eval` checks their output descriptors;
`Graph` holds contexts, builders, tensors and graphs; `Api` handles their byte protocol.
The page bindings call `web_api` operation 140. Float16 conversion also serves
BubblePopJS Float16Array, DataView and Math.f16round.

## Recovery and checks

Baseline main d799500c7: `/webnn/` 465 of Chrome's 13,986 subtests (610 names).
The prior check, https://github.com/danbri/factoidal-builds/actions/runs/43562650539,
built 73ea312f2 successfully and then stopped at the faulty tail-recursion gate;
its WPT tests did not run. Later validation fixes and the pending loop proofs still
require a cloud build. No local build is used for this recovery.

The retained changes replace recursive size, broadcast, ravel and unravel at compilation
with loops whose equalities are proved in the source. Concat input selection now carries
its part number in a loop; its offset theorem is preserved. Guards use shapes and axis
extents from WPT expand, transpose and concat validation cases.

## Assurance

**Proved in the earlier checked source:** broadcast commutativity and associativity;
flat/multi-index round trips and bounds; transpose index inverse; slice index bounds;
integer wrapping range/congruence; reshape buffer preservation; binary16 conversion
round trips by exhaustive finite proof; checked evaluator output descriptors.

**Proofs awaiting the current cloud check:** shape loop equivalences, concat loop offset,
constant integer sum/max reductions, descriptor bounds and inverse-permutation additions.
Each theorem's hypotheses and scope remain in its module.

**Tested only:** the predecessor reported 2,929 of 2,956 conformance cases and 1,111 of
1,132 validation cases in a one-device harness using V8 for scripts and the Lean library
for WebNN. These are diagnostic results, not the browser's WPT score. Floating-point
kernels and page bindings have guards and test vectors, not general numerical proofs.

**Open:** full graph execution refinement, all floating-point operator error bounds,
context/builder/tensor lifecycle invariants, browser WPT results and performance deltas.
No timing improvement is claimed for the loops without a measurement. Pages which do
not call WebNN do not execute its kernels; prelude startup overhead is unmeasured.
