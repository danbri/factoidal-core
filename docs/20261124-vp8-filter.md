# VP8 keyframe loop filter

The filter runs after intra reconstruction so all predictors consume unfiltered neighbours. The filtering raster visits vertical edges before horizontal edges within each macroblock. The simple variant filters luma alone. The normal variant also filters chroma, selects a two-pixel adjustment across high-variance edges and uses separate four- and six-pixel adjustments for internal and macroblock edges. It uses decoded segment strength, sharpness and mode adjustments.

The inner-edge decision needs the coefficient state rather than the transformed sample values. For a whole luma macroblock, the final DC coefficient includes the inverse WHT contribution. The recorded nonzero flag also accounts for coded AC positions, which the reference uses to decide whether to run the internal filter.

`across_rejects_jump` states that the two nearest samples can rule out filtering regardless of the other samples on the edge. The differential compares the filtered YUV planes against libwebp, including opaque and alpha-bearing BBC images and generated simple, normal and disabled-filter controls.

RGB conversion, alpha samples and browser integration follow this stage.
