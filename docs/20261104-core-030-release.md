# @factoidal/core 0.30.0 release — 2026-11-04

`@factoidal/core@0.30.0` is published and is npm `latest`. The registry confirmed
both at 16:33 UTC. This release makes the existing XMPP hosts and the new in-page
LWS storage export available to the Factoidal and FOAFOS experiments.

```sh
npm install @factoidal/core@0.30.0
```

## Scope and operational notes

The renderer worker, HTML/CSS/SVG conformance work, font branch and native HTML
app are separate follow-ups. This npm release does not add those host demos or
claim complete browser/SVG conformance. FOAFOS chat controls use the released
RDF/XMPP APIs and are a separate application change.

GitHub's [Actions incident](https://www.githubstatus.com/incidents/xr3myzj7ms51)
left job statuses stale while logs and artifacts advanced. Publication waited
for the exact web release and terminal successful web gate. npm then reported
processing before its registry exposed the accepted version; no duplicate
publication was attempted.

The local installer gained an explicit offline input mode so an allowed
downloader can fetch the official manifest/archive separately. Its normal
verification and stamp writer installed the exact release; no engine was
copied or restamped as a different source. See
[the installer record](20261104-offline-release-install.md).
