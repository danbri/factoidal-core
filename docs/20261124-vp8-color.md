# VP8 colour conversion

The last colour step crops the filtered VP8 planes to the declared image size. It interpolates the subsampled chroma with replicated boundaries and applies integer YUV-to-RGB conversion, then supplies native-layout straight RGBA. When an already-decoded alpha plane is supplied, its bytes are copied unchanged and the size must match the image.

`chromaWeight_constant` proves that the interpolator preserves constant samples. The successful RGBA result carries a size proof. The differential compares colour channels with libwebp on the archived BBC inputs and the same synthetic controls. For the alpha-bearing input, libwebp's independently decoded alpha plane is supplied to exercise the RGBA contract.

Decoding the compressed WebP alpha plane and plumbing the new codec into browser image loading remain open.
