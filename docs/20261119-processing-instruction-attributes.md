The parser reads XML names, XML whitespace around the equals sign and quoted XML pseudo-attribute values. It resolves predefined and numeric references. Numeric accumulation stops above the Unicode range. An ordered set detects duplicate names and the list preserves input order. Each pair consumes one unit of fuel, with an extra unit to check the end. Duplicates, invalid characters such as NUL, malformed syntax and exhausted fuel yield no attributes. The serializer escapes ampersand, angle brackets and double quote. It preserves a literal non-breaking space. Web API operation 172 uses the existing UTF-16 length-prefix codec. The framing separates an empty value from an absent value and preserves supplementary characters. Lean selects named reads and computes toggle results. The page binding converts arguments, decodes framed fields and applies a returned character-data edit. An effective toggle sends one write. A toggle that forces the current state sends none.

Two paths still need separate changes. The engine derives the attribute map from stored data on read. DOM mutation accepts local names such as `$foo` that the XML Name grammar rejects. Retaining such attributes after a mutation requires a distinct map with update and clone handling. The existing `createProcessingInstruction` host wire splits the target and data on NUL, so direct creation with NUL in data is also unfinished. The character-data setter can store NUL and exercises the parser's rejection independently.

`parseList_zero` states that zero fuel returns no partial list. `parseList_length` bounds returned attributes by the initial count plus fuel. `parse_length` instantiates that bound for processing-instruction data. These are bounds on results and fuel. `toggle_force_no_change` establishes that forcing the present state returns no replacement data for successfully parsed input. The escape/unescape round trip and loop equivalence theorems concern the character-list codec within Lean. The module requests individual axiom reports for all ten theorems.
