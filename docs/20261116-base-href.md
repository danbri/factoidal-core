# Script-set base URLs — 16 November 2026

The DOM script state now maintains the frozen base URL of the first HTML `base`
with a no-namespace `href` in document tree order. URL getters use the node's
owner document, including detached nodes. `Node.baseURI`, hyperlink getters and
the reflection-table URL rows use this state. The host prelude only forwards
queries and values; base selection and URL parsing stay in Lean.

[Design and validation](designissues/2026-11-16-frozen-base-url.md).
Related theorem pipeline item: https://github.com/danbri/factoidal-core/issues/514
(URL parser correctness; these are supporting DOM selection lemmas, not a
proof of parser conformance).

Base URLs are tracked from the first use of one (a URL getter, `baseURI`, a history
change, a frame), so a page that reads no URL pays nothing at mutations; once tracked, a
change selects again only when it can alter the selected base. A branch WPT check of the
first version: `url/` +588 subtests, `html/infrastructure/urls/` +61, no test worse.
Timings and the checks run are in the design record.
