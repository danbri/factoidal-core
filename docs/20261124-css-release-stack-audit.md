# Keep the CSS release stack audit current

The Linux release gate reported six CSS declarations. Replace the length-dependent counter value parser, the reversed-counter token rewrite and the first-match counter update with executable loops. The compiler uses the replacement functions through equality theorems, so the specification-level functions remain available to existing Lean proofs.

The other three entries describe their actual call paths. Calculation simplification now recurses in Calc.simpWith, the worker extracted from the previously listed Calc.simp. The viewport predicate and simplifier descend the calculation syntax. The first-letter range builder sorts three sets of ranges derived from the checked-in Unicode data, independently of document size. The gate still checks all declarations outside the named entries.
