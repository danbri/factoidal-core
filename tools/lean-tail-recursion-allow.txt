# Baseline for `tools/lean-tail-recursion-audit.py --gate`.
# Every declaration below recurses without a tail-call loop and is of a
# gated class (length, depth, counter, unknown).  The gate fails when a
# declaration of a gated class is not listed.  Removing a line is the goal;
# adding one needs a reason on the line.  Since 2026-10-10 a line holding `*`
# is an fnmatch pattern over declaration names.
# Markers after `#`:
#   (b)  the depth is the nesting of a document, schema, ontology or query
#   (c)  the depth has a constant or logarithmic bound
#   (s)  specification only: no function of the emitted C outside the
#        definition's own module and its theorem modules calls it (the line
#        names the check and the executed path that replaces it)
#   (a) PENDING <issue>  LENGTH- or VALUE-proportional over data; the issue
#        lists it for conversion; the line keeps the gate green meanwhile
#   UNTRIAGED <issue>  found by the 2026-10-10 repair (issue 750); no bound
#        stated yet; the issue tracks the triage
# The lines up to the first `# ---` section carry no reason: they are the
# first baseline, recorded before reasons were required (imported from
# danbri/factoidal in the 2026-10-09 split).
