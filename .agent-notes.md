- Authorization Server Discovery: 401 MUST carry WWW-Authenticate with
  resource_metadata (RFC 9728 §5.1) + Link rel lws#storage.
- Protected Resource Metadata: RFC 9728 doc; authorization_servers REQUIRED,
  >=1 issuer; resource = requested resource.
- Token Validation by a Storage Server: Bearer (RFC 6750); signature with
  jwks_uri key from AS metadata (/.well-known/lws-configuration), SHOULD
  cache, MUST support rotation; iss; aud includes storage IRI; exp, nbf,
  iat not in future; failure -> 401 + resource_metadata + error; policy
  denial -> reject.
- No DPoP in the LWS draft (Solid-OIDC requires DPoP; Solid server has
  Solid/Server/Auth.lean but Solid step does not call it).
