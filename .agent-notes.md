# wt-lws-binary agent notes (issue 889)

Task: https://github.com/danbri/factoidal/issues/889 — LWS/Solid bodies as bytes.
Branch claude/wt-lws-binary from origin/main 6cdb15aa.

Plan / decisions:
- ABI: lwsStep/solidStep served by callBlobIO (l4_call_blob_io): request body
  = IN region, response body = OUT region. Reason: lean4-wasm-export rules
  (bytes with no encoding; base64 refused for byte transport 2026-09-03;
  Lean copies the region, never gets a host pointer). callIO path keeps
  "body" (text) and adds "bodyBase64" both ways for non-UTF-8.
- HTTP.Request/Response gain `bytes : Option ByteArray := none` (some b: b is
  the content, `body` ignored). Response.content / Request.content accessors.
  Needed one mechanical edit of an anonymous constructor in
  LWS/Authorization.lean (no semantic change).
- Entry.body : ByteArray; Entry.text for RDF/ACL readers.
- Range = byte slice (ByteArray.extract), always 206 when satisfiable.
- ETag = mtime + FNV-1a-32 of the bytes for data resources.
- Snapshot format lws-snapshot-2 with bodyBase64; reads lws-snapshot-1.
- RDF media type + invalid UTF-8 on PUT/POST/PATCH -> 400 problem.
Status: starting implementation.
