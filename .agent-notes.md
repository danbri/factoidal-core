## Findings
- All readers (parseTurtle, parseTurtleText walk, TurtleChunkFold, TriG,
  TurtleLenient) reach collections only through readStatement ->
  readSubjectTurtle / readPredicateObjectList -> readObject -> readCollection
  -> readCollectionRest (Syntax/Turtle.lean, mutual block at line ~1206).
  So one repair in that block covers every reader.
- readCollectionRest recurses once per element (C self-call, not a goto).
- Blank-node order: element i's own blank nodes are allocated BEFORE cell i's
  node (readObject, then freshBnode). So "assign cells first" must keep that
  interleaving: pass 1 reads element, allocates cell node, pushes the cell on a
  reverse accumulator (tail self-call -> goto); pass 2 links cells newest first
  (linkCells, a fold).
- Tail-recursion audit: readCollectionRest is found as a self-call but classed
  `unknown` (the indexer does not locate mutual-block defs), so the gate passes
  before (issue 750).
