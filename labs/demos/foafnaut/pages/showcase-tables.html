Tables

Three tables with the CSS a browser would draw: a caption bar, a header row with a rule under it, zebra rows, numbers aligned right, cells that span columns and rows, and a totals row.

Expected failure. The engine has no table layout, so each cell is a block on its own line, and colspan and rowspan have no effect (issue 1272). Text-align and font-weight are dropped (issue 1273). Backgrounds, padding, colours and the caption work, so the cells keep their zebra colours. The same tables drawn as SVG: showcase-tables-svg.html.
