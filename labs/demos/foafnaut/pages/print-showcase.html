Print showcase

This page tests printing in foafnaut2525. Choose File, Print (Command-P). The Lean engine lays the page out again for the paper of the page setup, with the print rules of its style sheet, and breaks it into pages. The system print panel then prints it, or saves it as a PDF.

On screen you see this note. On paper it is not there: a print style rule hides it.

What the print rules do

An @media print block holds rules for paper only. This page has five:

- The note above has display none.

- Each chapter heading has break-before page, so a chapter starts on a new page.

- The figure and the table have break-inside avoid, so a page edge does not cut them.

- The text is black.

- The text column is the width of the paper.

Lines are never cut: a page ends at the last line that fits.
