Emoji draw in colour from Noto Color Emoji (SIL Open Font License), its COLR version 1 glyphs drawn by the engine's own Lean code: layers, linear and radial gradients, transforms and composites, through the same rasteriser as Canvas 2D (issue 1276). The font is cut into slices by kind of emoji (faces, people, flags by letter, ...), and the browser fetches only the slices a page uses. Each emoji is one glyph, and so is each sequence: the font's ligatures join ZWJ sequences, skin tones, flags, tag sequences and keycaps, and the engine keeps a sequence's characters in one font.

U+FE0E asks for text presentation: those emoji draw in one colour from Noto Emoji, an outline font, which is fetched only for a page that asks for it.
