# Markdown in the Lean engine

This page starts as Markdown. A small converter makes plain HTML, and the Lean engine lays it out and draws it with WebGPU.

## Why this page exists

- It is a test page for headings, paragraphs and lists.
- It has a [link back to the demo index](index.html).

Factoidal has no Markdown parser yet, so the converter is a temporary tool.
