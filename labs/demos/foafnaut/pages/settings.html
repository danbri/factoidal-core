Engine

Page scripts: which JavaScript engine runs the scripts of a page. BubblePopJS, the built-in JavaScript engine, is the default. QuickJS-NG runs inside BubblePopWASM, the built-in WebAssembly engine, for comparison. Pages opened after a change use it.

Search

Words typed in the address bar that are not an address go to no one: they open a page of this browser. This engine is older and has no search engine setting.

The address bar

Type a URL, words, or a command. Words open a page of this browser, or go to the search engine you chose above.

- :settings opens this page

- :back and :forward

- :reload

- :home

- :graph opens the interactive FOAF graph

- :source shows this page's source

- :new and :close

- :zoom 150, :zoom up and :zoom down

- :theme dark, :theme light

- :console shows what the page logged and what this browser skipped

- :search-engine and a name from the Search list, none, or an address with %s where the words go

- :open https://example.org opens your system browser

The browser keeps these settings: a reload or a new window starts with them.
