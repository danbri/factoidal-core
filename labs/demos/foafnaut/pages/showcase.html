Demo index

foafnaut showcase

What the Lean engine draws well today, and where it is weak.

Pages

Data visualisation

Bar chart, line and area chart, tidy tree, circle packing and a force-directed graph, computed in the manner of D3 with no library, from real data (this browser's own Lean files).

Works: paths, Bézier curves, dashes, opacity, rounded rectangles, many hundreds of shapes.

Data visualisation with a script

The same bar chart, but sized and animated by a script from a data array.

Gap: the window refuses pages with scripts, and the script binding has no timers (issue 1271).

Tables

A caption, a header row, zebra rows, numbers aligned right, colspan and rowspan.

Gap: no table layout, and no text alignment (issue 1272, issue 1273).

Tables drawn as SVG

The same tables, with zebra rows, a rule under the header, numbers aligned right, a spanning cell and a totals row.

Works as SVG shapes and glyph outlines placed at build time.

Lettering on curves

A badge with text round a circle, text on a wave and a spiral, words rotated in a ring.

Works as glyph outlines placed at build time; the engine draws the curves.

SVG text and textPath

The same lettering written as SVG text, textPath and rotate.

Works: text, tspan and textPath drawn with the page font (issue 1270). Vertical text is drawn horizontally.

Writing systems and direction

Latin with diacritics, Greek, Cyrillic, Arabic, Hebrew, Devanagari, Thai, Chinese, Japanese, Korean; right to left and mixed direction.

Each script draws from a fallback font fetched for the page (issue 1274). Gaps: no bidirectional layout or right-to-left shaping (issue 1275), and no Indic conjuncts yet.

Emoji

Single emoji, ZWJ sequences, skin tones, flags and keycaps.

Gap: no emoji font and no colour glyphs (issue 1276).

Test suites

The W3C SVG Tiny 1.2 suite, 496 tests, scored with WebGPU pixels against the W3C reference images: SVG Tiny pixel results. The strict Lean SVG compiler on the same files: SVG Tiny admission results.

All rendering and font suites (WPT, html5lib, HarfBuzz, the old web mirror, these demo pages): rendering and font scores.

Those links open the public hub. The pages there are large; the window draws them slowly.

Fonts

Noto Sans Regular (OFL), 3,884 glyphs: Latin with its diacritics, Greek and Cyrillic. Other writing systems draw from fallback fonts fetched for the page. There is no bold or italic face.
