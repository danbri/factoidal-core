WebGPU triangle, checked by the browser

This page's script draws a spinning triangle with navigator.gpu. The script runs inside the Lean engine: in BubblePopJS in the desktop app, in QuickJS-NG in the Lean Wasm VM on the Hub. Each WebGPU call is a typed command that Lean checks before the GPU sees it: the shader is parsed and checked against a small WGSL subset, every array index is clamped, every buffer write and every draw is bounds-checked, and the page has a GPU memory quota. Lean then draws the canvas into the page.

The script has not run: this engine has no page scripts or no page GPU.

Record: docs/designissues/2026-11-08-page-gpu.md. Lean: formal/lean4/L4Factoidal/PageGpu/.

What the script cannot do

Read pixels back, map a buffer, use storage buffers, textures or compute, loop without a literal bound, or name an object of another page or of the browser. Lean refuses each of these and the refusal reaches the page as a GPUValidationError.
