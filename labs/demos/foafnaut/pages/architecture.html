How foafnaut is built

Every part below is one file or a few. Links to GitHub open in your system browser, because this engine can not draw GitHub yet.

Parsing

- Tokenizer.lean: HTML tokenizer

- TreeBuilder.lean: HTML tree construction

- Parser.lean: XML parser

- NamespaceView.lean: XML namespaces

- Arena.lean: the DOM

Style and layout

- Style.lean: CSS selectors and computed style

- Layout.lean: block and inline layout

- Links.lean: link regions

- Scene.lean: the common scene

Fonts and text

- Font.lean: the bitmap font

- LeanFontShape.lean: the Lean text shaper

- SfntShape.lean: OpenType shaping

- SfntGpos.lean: OpenType positioning

- FontPolicy.lean: font trust and safety

SVG

- SVG.lean: the strict reader, and the WGSL shader

- SVGForgiving.lean: draw what can be drawn, and SVG fonts

- SVGPath.lean: paths

- SVGCurves.lean: curves

- SVGStroke.lean: strokes

- SVGDash.lean: dashes

- SVGCSS.lean: SVG style sheets

- SVGReferences.lean: references and use

Transforming documents

- WebXslt.lean: XML pages with xml-stylesheet

- Transform.lean: XSLT 1.0

- Interp.lean: XSLT 3.0 and 4.0

The browser

- WebDocument.lean: one page, from source to frame

- WebRender.lean: HTML and embedded SVG to a scene

- WebShell.lean: tabs, address bar and buttons

- WebHistory.lean: session history and keys

- WebSelection.lean: selection, copy and zoom

GPU

- RenderPlan.lean: WebGPU commands, chosen in Lean

- render_plan.ts: runs those commands

- gpu_transport.ts: offscreen sessions

Host, not Lean

- run_html.ts: the event loop

- native_window.m: the Cocoa window

- native_html_document.ts: fetches bytes
