Data visualisation

Five chart layouts in the manner of D3, made with no library. A Node program (tools/showcase-pages.mjs, plain ECMAScript) computes each layout and writes plain SVG; the Lean engine draws it. Every label is SVG text, which Lean shapes and draws with the held font (issue 1270).

The page does not use script. The desktop window refuses a page with a script, and the script binding has no timers, so the charts can not animate yet; see the scripted version and issue 1271.
