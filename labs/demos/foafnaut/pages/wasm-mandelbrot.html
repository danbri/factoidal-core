WebAssembly in a page

The page's script compiles a 310-byte WebAssembly module with the WebAssembly JavaScript API. Lean validates and runs it in WasmVM; the script reads the module's memory through Memory.buffer and draws it as SVG. Click the picture to zoom in.

The script has not run: this engine has no page scripts or no WebAssembly.

The module (wasm-mandelbrot.wat) exports mandel, its memory and a mutable global iterations, and imports env.row, a JavaScript function it calls after each row. The script only turns bytes into SVG paths: eight paths, one per colour band, so a picture is eight attribute writes.
