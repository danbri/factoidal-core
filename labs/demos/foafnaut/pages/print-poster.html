FOAFNAUT · A BROWSER ENGINE IN LEAN

Every pixel from the built-in engine

HTML, CSS, SVG, XSLT and fonts: parsed, styled, laid out and painted by Lean 4 code, then drawn by WebGPU.

The picture is SVG: two gradients for the sky and the sun, cubic curves for the hills, quadratic curves with dashes for the links, and radial gradients for the nodes. Everything on this sheet is drawn by the engine, on screen and on paper.

Cards to cut out, 1 to 3

Each card has break-inside: avoid, so a page edge does not cut it.

1. Parse

The WHATWG HTML tokenizer and tree builder, and an XML parser for XML pages, written in Lean. The DOM arena has Lean proofs about its insert and replace operations.

2. Transform

An XML page that names an XSLT stylesheet is transformed by Lean before layout. XSLT 1.0, and 2.0 to 4.0. Try the feed reader and the tables that compute.

3. Style and lay out

CSS selectors and the cascade, block and inline flow, word wrapping and tables. The print rules on this page are in the same style sheet as the screen rules.

4. Shape

Lean reads the font files, applies their substitutions and positions, and falls back to a second font for characters the first one lacks: Հայերեն.

5. Paint

SVG paths, strokes, dashes, gradients and transforms become one list of painted primitives, with proofs about stroke edges and dash patterns.

6. Draw

Lean writes the WebGPU buffers, the shader and the command order. The host only submits them, and for print hands the page images to the system print panel.
