WebGPU compute: a force-directed graph

This page lays out a graph of 1,000 nodes with WebGPU compute shaders. One compute shader moves every node by the forces of all the others and of its edges; a second writes the triangles and lines of the picture into a buffer that a render pass draws. Every few seconds the page copies the nodes into a mappable buffer and reads it back with mapAsync to report the layout's extent and speed. Each call is a typed command that the built-in engine checks before the GPU sees it: the shaders are parsed and checked against a WGSL subset, every index of a storage array is clamped to the array's length, every loop has a bound, and every dispatch counts against the page's GPU work for a frame.

The script has not run: this engine has no page scripts or no page GPU.
