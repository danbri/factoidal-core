Foafnaut is a web browser written in Lean. It parses, lays out and draws every page with its own engine, and paints with WebGPU.

Foafnaut's own pages

On the live web

The newest copy of the demo pages, as deployed to the Hub. It needs a network connection.

Bundled with this app

The copy compiled into this app, of the same age as its engine. It works offline.

Not yet: BBC, GOV.UK and Lobsters (module scripts); Wikipedia and W3C (stylesheet media conditions); NHS (an SVG class attribute and DOM methods); Project Gutenberg (a CSS number); lite.cnn.com (a script error stops the page).

The engine is new. Many sites do not draw yet, or draw only in part: a page is refused when it needs a feature that Lean does not implement (for example module scripts). Liberal mode, in Settings, draws such a page without what Lean skipped, and lists each skip in the console.
