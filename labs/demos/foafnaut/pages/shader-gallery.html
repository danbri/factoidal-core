This page needs scripts and WebGPU or WebGL 2.

Two triangles cover the canvas; a fragment shader colours every pixel from iTime, iResolution, iMouse and iFrame. Each shader is here twice: in WGSL for WebGPU and in GLSL ES 3.00 for WebGL 2. In Foafnaut, Lean parses each one, checks it against a small subset (loops with literal bounds, no recursion, a cost bound, every index clamped) and prints the WGSL the GPU gets. Drag on the picture to move iMouse.

The five shaders are written for this page (MIT, like the rest of the repository); none is copied from Shadertoy.
In Foafnaut every WebGPU and WebGL call is a command that Lean checks (L4Factoidal.PageGpu; record
docs/designissues/2026-11-08-page-gpu.md); a frame is one uniform write and one render pass. The readout counts frames
on the page's own clock; script is the time the page's frame callback takes on that clock (in Foafnaut a clock of
script steps); Lean is Foafnaut's wall time for the page's last turn: the script, and Lean's check of the frame's
commands (navigator.foafnaut, Foafnaut's own).
